# .claude/workflows — 动态编排

> 把一个或多个 Skill 与 CLI 临时组合起来；脚本决定分几段、每段派几条、什么时候收，
> 模型负责每一条具体怎么做。

本项目主要使用 Codex；同一评审方法的 Codex 主入口是 `$km-review`，正文正本位于
`skills/km-review/SKILL.md`。本目录只保留 Claude Code 兼容实现。

这里是 Claude Code 的工具专属位置，不是跨工具通用规范。可迁移的是编排思想，具体文件
位置和语法随工具变化。

## 当前工作流

| 文件 | 职责 |
| --- | --- |
| `km-review.js` | 从患者可懂性、工程事实和医学安全三个互异视角并行评审，按 P0–P3 汇总 |

多视角评审只检查事实、逻辑、安全和合规，不裁决作者的风格偏好。收工判据固定为：
P0、P1、P2 清零，P3 由作者按成本和收益决定。
