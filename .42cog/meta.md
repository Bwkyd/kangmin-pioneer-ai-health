## 交接

这个系统是客户项目的交付物，由作者开发并交付；交付后分别服务患者和运营人员：

```text
客户提出并确认需求与资料 ──▶ 作者开发并交付 kangmin ──▶ 患者使用 / 运营人员维护
```

| | 是谁 | 交接什么 | 怎么交 |
| --- | --- | --- | --- |
| 项目委托方 | 客户 | 经确认的范围、医学、内容与页面资料 | 由作者确认并登记到 `vault/truth/` |
| 开发与交付方 | 作者 | 按确认范围开发、联调并交付系统 | 交付患者微信小程序与管理后台 |
| 系统使用方 | 患者 | 使用鼻健康管理服务 | 微信小程序 |
| 系统维护方 | 运营人员 | 维护文章、视频与智能体知识库 | 管理后台 |

## 依赖

| 依赖 | 版本 | 缺了会怎样 |
| --- | --- | --- |
| Git 与 GitHub 仓库访问 | Git 2.x；远程 `Bwkyd/kangmin-pioneer-ai-health` 的 `main` | 无法取得和同步受版本控制的项目文件 |
| Node.js 与 npm 依赖 | Node.js `22.13.0`（`.nvmrc`，最低版本同为 `22.13.0`）；依赖由 `src/package-lock.json` 锁定 | 无法安装、构建、测试或运行当前主实现 |
| 客户确认资料 `vault/truth/` | 当前有效版本；不进 Git，安全迁移方式待作者确认 | 无法判断范围、医学、内容和页面事实，开发与验收失去权威依据 |
| 环境配置与密钥 | `src/.env` 当前有效配置；不进 Git，具体变量见 `src/.env.example` | 本地可按代码定义降级；正式环境会因数据库、对象存储、加密或身份配置缺失而拒绝启动 |
| PostgreSQL 服务 | 正式环境必需；具体版本待客户购买时确认 | 正式环境无法持久化患者与运营数据 |
| S3 兼容对象存储（腾讯云 COS） | 正式环境必需；Bucket、地域和凭据以购买后的配置为准 | 正式环境无法保存文章素材、视频和知识文件 |
| 微信小程序账号 | 正式交付必需；AppID 与 AppSecret 以客户账号为准 | 无法启用正式微信身份链路或承载最终患者端 |
| 外部大模型 API 账号 | 当前模型与切换状态见 `real.md` | 确定性流程仍可降级运行，但无法提供动态知识问答与自然语言解释 |

**换台机器能否完整接续，不只看代码能否运行，还要确认 `vault/truth/` 与环境密钥已通过
安全方式迁移。**
