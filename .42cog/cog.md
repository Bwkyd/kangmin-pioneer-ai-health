# 认知模型 · kangmin

> 陈述句：这个系统里有哪些东西，谁产生、谁是谁的输入。模型变了就改这里。

- 创建：2026-08-13

## 实体与流转

| 实体 | 谁产生 | 是谁的输入 |
| --- | --- | --- |
| 问卷（题面/选项/顺序） | `vault/truth/页面展示.md` | 患者作答 → 决策树 |
| 决策树/规则引擎 | 代码实现 truth 前置规则与证型树 | 判定 → 诊疗参数 |
| 诊疗参数（证型、分期、穴位清单、外治方式、约束规范） | 决策树判定 | Prompt（方案生成） |
| 知识库分块 | 运营上传 + truth 材料 | 检索 → 模型回答 |
| 大模型（千问/DeepSeek） | 外部 API | 方案文本 / 追问回答（只解释不判定） |
| 会话（问卷轮次 + 追问上下文） | 患者与服务交互 | 追问检索与生成的上下文 |
| 方案与视频 | 判定参数 + 模型生成；视频引用 truth《视频大全》 | 患者可见内容 |
| 文章/视频/站内消息 | 运营管理 | 患者「学一学/我的」 |

## 权威流向（不可逆）

客户与报价 → `vault/truth/` → 代码与验收；AI 推断没有权威，冲突或缺失时停下待作者确认。

## 患者问答三闭环（收敛方向落在哪）

1. **问得答**：提问 → 检索 truth 知识库 → 模型受约束生成（失败摘录降级）→ 回答+来源。
2. **答得方案**：问卷 → 决策树 → 诊疗参数 → Prompt → 方案文本（科普化、差异化）→
   视频引用。
3. **问得下去**：方案后追问 → 会话上下文 + 参数约束 → 模型回答 → 继续追问。
