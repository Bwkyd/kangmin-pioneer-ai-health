## 收敛方向（一句话）

让过敏性鼻炎患者的每一个健康问题，都能在本系统得到**有依据、说得俗、问得下去**的
回答与方案：判定靠规则引擎，表达靠大模型，追问靠会话。

## 关联度量（每件产出与方向的关联度怎么量）

每件产出必须落到三个闭环之一，量不出关联的产出不做：

| 闭环 | 量法 |
| --- | --- |
| 问得答 | 患者提问 → 回答可追溯到 truth 知识库；零命中明说依据不足 |
| 答得方案 | 问卷 → 决策树 → 诊疗参数 → 通俗方案 + 视频引用 |
| 问得下去 | 方案后持续追问；名单外穴位/疗法零出现 |

## 真难题（三级过滤后留下的）

**医疗安全约束下的生成式对话**：在决策树给出的诊疗参数白名单内，让大模型把医学条目
变成老百姓的话、按人群（青少年/成人）与轻重（轻症/重症）微调表述，还能持续追问——
同时名单外穴位/疗法零出现。

| 判据 | 结论 |
| --- | --- |
| 手工能绕过（慢一点但做得完） | 不能——客户要的就是对话体验，模板=死板，已被客户两轮反馈证伪 |
| 一句提示语、一个单点工具能解决 | 不能——约束遵守率、多轮上下文、降级都要工程结构；research 002 已确认无现成开箱件 |
| 多年反复投入仍未解决 | 是——领域专属空白，客户两轮迭代都卡在这 |

## 排除清单（一条不做的，抵十条要做的）

1. **不做 AI 自主诊断**：证型/分期判定永远归决策树 + truth，AI 只解释、答疑、科普
   （报价表与客户修改想法第 1、4 条双确认）。
2. **不生成超出 truth 的医学内容**：名单外穴位/疗法、未确认结论一律不产出；越界
   输出 fail-closed。
3. **不做写码型 agent 工具生态**：不引入 opencode/pi 全套，只借最小循环结构
   （模型↔工具↔结果）。
4. **不做报价外能力**：2,800 元 / 15 个工作日之外的新增组件（向量库、embedding、
   新模型成本）先作者拍板。
5. **不维护同内容副本**：truth 不建 raw/加工副本；方向类内容不抄进 CLAUDE.md/board。
