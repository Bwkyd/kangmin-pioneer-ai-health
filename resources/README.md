# resources：外部参考区（只读）

本目录保存**他人的材料**：文献、竞品、参考文章、行业资料等，供开发与决策时参考。

边界：

- **只读**：本目录材料由 Agent 引用不修改；引用时注明出处。
- **不裁决**：权威与验收依据仍以 `vault/truth/` 为唯一真相源，本目录只作参考，
  不参与范围、价格、工期和内容的裁决。
- **版权红线**：只放可合法引用与分发的内容；不可公开复制的材料放 `notes/`
  （作者私区）或 `_work/`（过程材料）。
- **不建副本**：与 `vault/` 同内容的不重复存放；`vault/raw/` 已明确不存放加工稿。
