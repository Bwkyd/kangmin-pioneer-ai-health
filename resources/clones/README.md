# resources/clones/ · 外部克隆仓（不进仓）

`clone.sh` 拉来的第三方开源仓统一放这里（如 `resources/clones/docling/`）。

- **不进 git**：`.gitignore` 忽略本目录（`resources/clones/**`），一条 `git clone` 就能重建，不占仓库。
- **只读借鉴**：读懂 → 自己写，绝不复制粘贴进作品区；先查 LICENSE（GPL/AGPL 只参考不链接）。
- **手工收集的参考材料**（文献、竞品资料等不可重建的）放 `resources/` 根下，随仓库提交。
