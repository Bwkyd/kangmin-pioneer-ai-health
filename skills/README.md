# skills — kangmin 自产技能

> 采用 Agent Plugins 1.0.0 布局：`skills/<name>/SKILL.md`。所有项目技能共用根目录
> `plugin.json`；外部插件依赖登记在 `42plugin.json`。
> Codex 按官方规则从 `.agents/skills/` 发现仓库技能；本项目使用相对符号链接指向这里的
> 唯一正本，不复制 `SKILL.md`。

只把已经验证、输入输出稳定、值得跨任务复用的流程固化为技能。一次性程序放 `_work/`，
可机械判断的仓库检查放 `scripts/`；不存在的能力不得宣称可用。

## 增删判据

新增前回答三问：是否与现有能力重复、触发条件是否明确、是否解决了已有能力无法解决的
稳定缺口。人类入口控制在两个常用技能、四个上限；复杂步骤优先作为主技能的子能力。

## 三层能力

- 元能力：产生并维护可安装技能的能力，例如四步走。
- 核心能力：跨领域通用的分析、论证和决策方法。
- 专属能力：只对鼻健康管理项目有效的流程与检查。

修改技能或插件清单后运行 `python3 scripts/check-manifests.py`。
