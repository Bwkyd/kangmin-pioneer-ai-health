# 外部评审先核对有效请求与完整终态

CLI 接受模型或思考开关，不等于兼容供应商实际收到同样参数。连续评审超时且只有思考
事件时，先用脱敏请求元数据定位有效 model、thinking 与输出预算，避免反复增大超时。
子进程环境可能被 CLI 用户设置中的同名 env 覆盖，应核实实际目标，而不是只查看 shell。

保持作者指定的 CLI、模型厂商、认证和只读权限；如需在单次评审进程中补充供应商兼容
字段，只能转发到原已核实的官方 HTTPS 上游，不改全局配置，不输出认证头、密钥或思考
正文。提示词先写成冻结文件，独立路线读取相同内容，不互相传递评审意见。

每条路线须保留工具版本、请求模型、真实响应模型元数据、完整终态和可用评审正文。
连通成功、出现思考事件、配置已保存或模型自报均不能替代正式审核；超时应如实记为
未完成，不能静默换模型或用另一条路线替代。
