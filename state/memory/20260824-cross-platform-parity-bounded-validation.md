# 跨端同构按当前基准逐页有界验证

当一个客户端被要求与另一个现有客户端保持一致时，先以当前运行实现和对应资源作为跨端表现基准，逐项登记
结构、文案、入口、状态、资产和关键视觉值；旧客户端、旧截图和历史文档只能帮助发现差异，不能反向覆盖
当前表现基准。这个基准只裁决跨端一致性，业务范围、价格和医学事实仍服从对应 `vault/truth/`；运行实现与
truth 冲突时停止迁移并登记决策点，不能把错误同步到新端。

一次只选择一个可独立验收的页面或流程，明确平台强制差异、通过线和停止线。样本未通过时不扩大迁移；
样本通过也只证明该切片，不能外推为全站一致。

验证证据分层保留：源码与资源映射证明实现意图，自动化回归证明结构和旧功能，平台工具编译与交互证明
真实运行路径，真机截图和人工操作才证明视觉、安全区及平台体验。WXML/DOM 已挂载、控制台无错或上传成功，
均不能替代后一层证据。

对已经出现过的分叉增加正反两类回归：既断言当前文案、资产和比例存在，也明确拒绝旧文案、旧颜色、旧尺寸
或旧入口重新出现。跨单位转换应记录确定映射并锁定关键值，避免凭视觉印象逐次漂移。

单次页面、工具版本、测试数量、截图和上传版本留在实验或变更记录，不进入长期记忆。
