# 决策前置化与确定性分流

能由 Agent 在现有授权、truth 和书面标准内确定，且可逆、低风险的事项直接推进；会改变方向、
范围、医学规则、作者口味或对外状态的真实分叉，整理证据、选项和推荐项交给作者拍板。

## 应用方式

- 先区分只读回答、诊断和明确实现，不为可确定事项增加多余询问。
- 交互、文案等实现细节可在既有标准内采用可逆默认方案；存在真实方案分叉时先做有界实验。
- 医学规则、客户资料语义或同一职责的 truth 冲突时停止推断，登记决策点。
- `docs/product/` 记录客户拍板与追溯过程，但不自动成为范围或医学事实的裁决源；相关决定只有
  经作者确认并按职责写回对应 `vault/truth/` 后，才能作为开发与验收依据。
- “待客户确认”只表示未决状态，不能作为实现授权或临床审核结论。
