# 小程序交互命中区与图标几何同源

自定义导航中的图标不要只按截图调视觉位置，再把点击事件绑到尺寸和默认样式不透明的原生组件。
应让固定尺寸的普通视图同时承担布局与点击命中，内部图形只负责绘制；这样视觉位置、可访问标签
和实际点击范围由同一个盒子约束。

十字、汉堡线等简单图标优先用两条或三条 CSS 几何线绘制，不依赖字体 glyph 的字面框和基线。
布局验收除点击图标中心外，还要点击紧邻边界、标题中部等负向坐标，确认不会误触；抽屉打开、
遮罩关闭、页面隐藏和卸载时都要回读底栏与遮罩状态，避免跨页残留。

结构测试负责拒绝原生按钮和字体符号回流，真实开发工具坐标点击负责验证运行时命中盒。截图只能
证明外观，不能单独证明点击范围正确。
