# 知识兜底必须复用正式输出校验

## 模式

模型超时、返回空值或输出未通过医学边界校验时，可以尝试用检索到的 enabled 知识原文
兜底，但知识库状态不能替代患者输出校验。每条候选原文必须独立通过与模型回答相同的穴位、
疗法、数值和疗效约束；首条合格内容才可展示，全部不合格则继续固定安全降级。

## 为什么

- 后台启用只证明资料可检索，不证明其中每个操作都属于当前患者方案。
- 模型波动不应让已审核、与问题相关且边界内的事实完全不可见。
- 模型答案与知识兜底共用同一校验器，能避免两套医学边界逐渐漂移。

## 回归要求

- 覆盖模型返回空值后，合规知识原文可见且带来源。
- 覆盖知识原文含当前方案外疗法时仍被拒绝。
- 用真实生产切片跑一次回归，避免只用过度简化的测试句掩盖中文上下文误判。
