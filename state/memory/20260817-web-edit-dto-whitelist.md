# Web 编辑请求只提交可编辑字段

## 规则

列表或详情接口返回的实体不能直接整体放进编辑表单后再展开提交。应显式白名单选择页面允许
编辑的字段；`id`、修订号、状态、时间戳、派生字段和页面不负责维护的隐藏业务字段留在服务端。

## 为什么

读模型通常比写模型更宽。整体回传会把空数组、派生状态或旧版字段误解释为显式更新，既可能
触发校验失败，也可能覆盖服务端权威状态。类型声明若比运行时响应窄，展开对象仍会携带这些
类型系统看不到的字段。

## 验证方式

浏览器回归至少走一次“创建 → 从列表打开编辑 → 修改 → 保存 → 权威回读”；只测创建和发布
无法证明编辑入口真的可用。对关键内容再继续验证发布端读取的是编辑后的版本。
