# 深层 CLI 命令必须走真实进程验收

CLI 是独立适配器。直接调用应用服务只能证明命令处理逻辑存在，不能证明用户输入经过命令分段、参数解析和认证后能够到达它。命令层级变深或新增子命令时，必须把实际可执行文件作为验收入口。

## 做法

1. 从已注册命令表匹配最长合法前缀，不用固定段数猜命令名；剩余参数再交给选项解析器。
2. E2E 启动真实 CLI 进程，断言退出码、结构化输出和持久化回读，不用同进程应用调用代替。
3. 至少覆盖最深命令的成功路径、必填参数、未知命令、业务拒绝和帮助文案；涉及层级结构时同时覆盖最大深度和反向清理。
4. 部署切换前，在生产数据副本和候选制品上重跑同一入口，确认发布包中的编译产物而非工作区源码可达。
5. HTTP、Web 或其他适配器仍需各自的真实入口测试；一个适配器通过不能替另一个适配器背书。

## 停止条件

真实进程能从用户输入贯通到数据回读，负向路径按约定失败，测试产生的临时数据和会话已清理，才可以声明该入口跑通。
