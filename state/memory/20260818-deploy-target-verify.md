# 部署目标先核实

部署前不能凭主机名、私钥文件名或记忆中的服务名推断目标。先从现行部署记录反查主机、用户和
密钥指纹，再通过只读检查交叉确认：

1. 使用 `systemctl cat <服务名>` 核对 `ExecStart`、`WorkingDirectory` 和环境文件。
2. 将远端代码结构、启动命令和 release 标识与本地 `package.json`、目标提交和制品哈希比对。
3. 确认反向代理端口、数据库实际路径、备份位置和回滚 release，不把同机其他服务当成本项目。
4. 部署前排除环境文件、凭据、`.DS_Store` 等敏感或无关内容。macOS 自带 `bsdtar` 不支持
   GNU tar 的 `--transform`，需要目录改名时使用 `-s` 或先构建明确的制品目录；跨平台上传
   文档或批量数据时使用 `COPYFILE_DISABLE=1 tar --no-xattrs`，并在解包后断言不存在 `._*`
   AppleDouble 伴生文件，避免它们被误当业务输入。
5. 切换后回读服务状态、运行版本、探针和数据完整性；验证结果只说明对应环境，不扩大为生产或客户验收。
