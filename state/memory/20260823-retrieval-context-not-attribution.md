# 检索候选只是回答上下文，不是患者侧引用

## 模式

语义检索返回的 Top-k 只表示候选片段与查询相近，不表示片段真正相关、模型实际采用，或内容已
获得临床授权。普通患者问答可以把候选片段作为一次生成的上下文；没有命中、检索失败或候选不
相关时，允许模型用可靠的一般医学知识自然回答，不把内部检索状态暴露给患者。

## 为什么

- Top-k 排名不能证明模型在最终回答中采用了某一片段，机械展示会造成错误归因。
- 后台 enabled 只表示资料可检索，不能把知识资料提升为证型、分期、方案或操作参数的裁决依据。
- 用检索原文直接兜底会把候选相关性、患者适用性和临床授权混为一件事，还可能造成答非所问。

## 实现与回归要求

1. 普通问题最多一次检索、一次生成；不增加第二次意图判断或模型审阅。
2. 系统提示明确要求只采用相关片段，并在片段不相关时忽略它们。
3. 患者侧不把 Top-k 候选冒充来源；后台检索测试可以继续展示候选和相似度。
4. 急症、明确个体药量和专业操作参数仍在模型前确定分流；问卷、证型、分期和方案继续由
   truth 与确定性规则裁决。
5. 回归同时覆盖有命中、无命中、检索失败、无关候选、评估上下文隔离和患者历史恢复。
