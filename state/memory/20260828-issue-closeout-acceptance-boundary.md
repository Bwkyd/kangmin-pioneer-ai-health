# Issue 关闭与验收边界

任务单关闭可以表示当前交付范围已经收口，也可以表示作者决定把后续反馈转为新的问题单；它本身不能证明客户逐项验收、体验版可见、真机通过或生产发布完成。

当作者选择按交付节奏关闭一组任务单时，必须同时在 Issue 评论、状态板和变更记录中写清：

- 关闭的管理原因和当前代码、测试、上传证据；
- 尚未完成的外部条件，例如正式配置、真机、客户或生产验收；
- 后续反馈如何新建问题、需要携带哪些复现证据。

后续判断不能把 `CLOSED` 当作验收证据，也不能把开发版上传或自动化测试扩大为体验版、审核、生产或医学批准。若正式验收重新成为当前目标，应建立新的验收任务单并重新执行对应门禁。
