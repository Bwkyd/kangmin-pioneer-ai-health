# 有序决策树必须保留节点身份

## 模式

业务材料以“第 1 步 → 分支 → 第 N 步 → 终点”定义决策时，不能只把同名问题压缩为一个事实字段，再用无序条件组合模拟整棵树。即使题面相同，不同步骤的再次询问也可能是独立的确认节点，必须保留节点身份、进入条件、回答记录和终止语义。

实现至少需要区分：

- 当前节点，而不只是已经收集的字段集合；
- 同题首次回答与二次确认；
- 每个选项的精确跳转，不能把 A/B/C 粗略压成布尔值后丢失分支；
- 命中终点后立即停止主判定；
- 辅助印证题只用于展示或校验，不得反向覆盖主树结果。

## 验证

端到端测试应由客户树自动生成每条根到叶路径，并断言：题目顺序、未进入节点不出现、二次确认单独保存、终点后不再追问、最终分类与叶节点一致。类别占比只作为监测异常的信号，不能硬编码成诊断配额。
