# 多工具入口必须指向同一技能正本

## 触发条件

项目同时支持 Codex、Claude Code 或其他 Agent，已有工作流只放在某一工具专属目录，导致
主要工具无法发现，或文档普遍把兼容入口写成主入口。

## 做法

- 先查主要工具的官方发现规则，不凭另一个工具的目录结构类推。
- 把跨工具工作流的正文保留为一份可移植技能正本；工具发现目录使用相对符号链接或官方
  支持的清单指向正本，不复制内容。
- 把仓库通用规约放在主要工具原生读取的入口；兼容文件只作同步副本，并用脚本校验一致。
- 把真正工具专属的配置与编排留在各自目录，并在目录说明中标明主入口、兼容入口和边界。
- 用新会话实际调用技能，核验工具加载的最终路径，而不只检查目录是否存在。

## 边界

符号链接必须使用仓库内相对路径，避免换机失效。不同工具不支持同一种执行语法时，只共享
方法和判据，不强行共享不可移植的执行文件。
