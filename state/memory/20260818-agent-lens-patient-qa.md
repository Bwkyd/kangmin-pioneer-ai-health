# 智能体调研先定角色：患者科普问答型，不是写码型

## 适用场景

为 kangmin 的智能体能力做调研、派活或借鉴外部 Agent 框架之前。

## 强制做法

1. 先按 `.42cog/intent.md` 和 `AGENTS.md` 确认角色：本项目智能体提供通用科普、问卷引导、
   规则判定后的通俗解释与追问，不是自主诊断或执行型 Agent。
2. 借鉴写码型框架时只取与患者问答确实相关的最小循环、工具约束和验证思路，不照搬其工具集、
   权限模型或代码工程习惯。
3. 使用外部实现前先核对来源与许可证；泄露、未授权或不可公开复制的源码不抄实现、不克隆入库。
   合法第三方参考放入 `resources/clones/` 并保持只读，不获得项目裁决权。

## 边界

问卷顺序、证型、分期和方案匹配只由对应 `vault/truth/` 与确定性规则裁决。后台知识库只提供
可检索的问答依据，不能自动提升为临床规则；模型只能做受控候选提取、知识问答和通俗转译，
不得新增名单外穴位、疗法或操作细节。
