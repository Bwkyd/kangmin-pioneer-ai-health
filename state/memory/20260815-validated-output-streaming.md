# 生成式输出先验证再流式展示

## 模式

患者侧生成内容存在安全、合规或权限边界时，不把模型原始 token 直接发送给界面。先在服务端
完成生成、完整输出校验与持久化，再把已通过的权威正文按小块流式展示。

## 最小闭环

1. 业务服务只返回完成校验并已落库的最终正文。
2. 传输层用 NDJSON 等可增量解析格式发送 `start → delta* → done`；反向代理显式关闭缓冲。
3. `delta` 拼接结果必须等于 `done` 中的最终正文，也必须等于刷新后读取的持久化正文。
4. 客户端断流后不自动重试可能已提交的写命令，提示刷新并从权威存储恢复。
5. 测试同时覆盖协议分片、浏览器可见递增、断流语义和刷新恢复，不能只断言最终文本。

## 适用边界

这会保留生成阶段的首字等待时间，但能防止未校验内容短暂暴露。只有在可以对增量片段独立、
完整地执行同等安全校验时，才考虑进一步降低首分片延迟。
