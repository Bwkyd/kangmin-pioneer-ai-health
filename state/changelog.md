# kangmin 演化记录（给人类）

> 本文件回答三问：**变了什么、为什么变、对你意味着什么**。每个里程碑一条，倒序追加。
> 想看更细：AI 工作流水见 `state/board.md`，完整历史见 git log。规则见 `meta/kangmin_directory-protocol.md` 第二节。

## 2026-08-22 · 患者智能体只在医学硬事实处要求确定依据

**变了什么**：Issue #238 已实现、CI 验证、合并并部署；方案首答、追问和独立知识问答
现在共用同一个患者可见发布门，在诊断、证型、期别、方案、操作参数、药物、禁忌和明确
因果等硬事实没有当前依据时自然降级。

**为什么变**：旧校验一方面会因问题里出现方案外疗法词而过早拒绝自然科普，另一方面又
不能统一拦住无依据诊断、药量、因果和患者事实，边界既窄又漏。

**对你意味着什么**：患者仍面对同一个连续对话智能体，不需要选择用途分类；它可以用普通
语言解释和追问，但不能把模型或检索资料自动提升为个体诊断与操作方案。Web 试用环境已
切换到 `main@530e23c`，旧 release 与切换前数据库备份保留回滚；这不等于临床批准或客户验收。

## 2026-08-22 · 患者智能体可按自然问法使用知识工具

**变了什么**：Issue #237 已实现、CI 验证、合并并部署；完成评估后的同一个智能体现在可
根据自然问题直接回答，或改写一条检索词并执行一次只读知识搜索，零命中时自然说明缺口。

**为什么变**：旧逻辑只有患者明确点名当前方案穴位才检索，一般鼻健康问题和同义问法无法
使用已启用知识；固定拒答也割裂了连续对话体验。

**对你意味着什么**：不需要先选用途或人群模式，患者可直接提问；证型、分期和方案仍由
确定性规则裁决，急救表现由服务端硬阻断，模型不能新增方案外操作。Web 试用环境已切换到
`main@dd76967`，旧 release 与切换前数据库备份保留回滚；这不等于临床批准或客户验收。

## 2026-08-22 · 全部启用知识切换为语义检索

**变了什么**：Issue #236 已实现、CI 验证、合并并部署；知识检索从字面 `LIKE` 改为
`text-embedding-v4` 语义 Top-k，全部后台已启用知识进入同一检索集，来源、分类和相似度可回读。

**为什么变**：既有实验中同义问法的字面 Hit@3 只有 2/10，语义检索为 10/10；按当前小语料
采用应用内精确余弦即可闭环，无需引入新数据库扩展、用途分类或通用 Agent 框架。

**对你意味着什么**：换一种说法也能找到已启用知识；证型、分期、方案和操作参数仍由原有
确定性规则裁决，相似度不提供医学授权。Web 试用环境已切换到 `main@af5d74a`，旧 release 与
迁移前数据库备份保留回滚；这不等于临床批准或客户验收。

## 2026-08-22 · 患者智能体路线收敛为报价内语义 RAG

**变了什么**：完成小荷 AI 医生、Pi、DeepSeek Harness、提示词、上下文、语义检索和模型
替换的有界调研；最终不训练、不切换生产模型、不引入新 Agent/评测平台，把后续实施拆为
GitHub #236–#238：语义检索、自然问答链和医学硬事实发布条件。

**为什么变**：实验已证明字面检索是“换说法找不到”的直接原因，单独换提示词、上下文或
更强模型仍会补出无依据医学细节；训练又不属于 2,800 元报价范围。继续扩展技术路线会增加
成本，却不改善当前报价内闭环。

**对你意味着什么**：下一轮开发有唯一顺序和书面验收线；规则引擎继续裁决证型、分期和
方案，模型只通过受限搜索工具获取后台已启用知识并做追问、解释和通俗转译；不增加知识用途分类。当前只是路线与任务
就绪，不等于代码已实现、客户验收、临床批准或生产上线。

## 2026-08-18 · 管理后台运营文案一致性收口

## 2026-08-18 · 报价内管理工作台首轮合并并部署

**变了什么**：管理后台从统计式单页收敛为按报价交付的任务型工作台，首页提供待办队列和入口，文章、视频、知识库与应用内站内消息具备搜索、状态筛选、状态解释和下一步提示；元反思修正了知识索引待办计数、队列状态聚焦和旧的“可用素材”统计。PR #222 已 squash 合并为 `main@4c5ead7`，并部署至 Web 试用环境 `admin-workbench-4c5ead7`。

**为什么变**：旧后台虽然已有服务端能力，但运营人员只能看到演示式统计和列表，无法从报价条目直接完成“找到—处理—回读结果”的工作。此次只复用既有管理命令与状态机，不扩展微信订阅通知、BI、用户/模型/临床规则后台，也不改变患者端与医学边界。

**对你意味着什么**：可从 [Web 试用环境](https://140.143.120.176/admin) 直接验证新的运营路径；云端保留 SQLite 回滚备份，服务与数据库冒烟通过。`/ready` 仍因试用环境未配置加密密钥返回 503，因此本记录不等于正式生产就绪、医学批准或客户验收。

**对你意味着什么**：原生小程序代码已进入主分支并通过上传接口验证；下一步只剩客户侧微信
账号权限、合法域名、登录配置、真机和体验确认，不需要重复 Web 部署。操作细节见

## 2026-08-15 · 诊一诊智能体进入客户试用反馈阶段

**变了什么**：Web 试用环境已跑通确定性问卷判定、患者级评估继承、千问受约束转译与连续

**对你意味着什么**：当前 Web 小闭环可以交给客户体验，项目转入“待客户反馈”；后续只根据
实际反馈收敛，不把作者侧测试通过冒充客户验收，也不提前扩大到整本手册、正式生产或原生小程序。
