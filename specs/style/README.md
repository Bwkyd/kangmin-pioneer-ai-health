# style：产出风格标准

> 本目录管「产出该长什么样」。品牌事实（已确认的 Logo、颜色、字体、语气与文案）
> 在 `vault/style/`——事实归 vault，标准归这里，两处不互相复制。

形容词式自述不能定标；作者亲手修改并确认的成品才是风格原件。正例给出方向，负例形成
护栏，能机械检查的负例继续固化进 `scripts/`。

## 风格档案

| 文件或目录 | 内容 | 状态 |
| --- | --- | --- |
| `positive.md` | 作者确认的正例及适用范围 | 待作者提供定标样本后建立 |
| `negative.md` | 会毁掉产出的反例、原因与检查方式 | 待从实际改稿中提炼 |
| `lexicon.md` | 禁用词、替换词和术语体例 | 待从客户与患者文案中提炼 |
| `samples/` | 改前与改后成对的定标样本 | 待出现可合法保存的样本后建立 |

不伪造空白“标准”，也不把未经作者确认的 AI 文案登记为正例。

## 文档

- 全中文；文件名默认英文（kebab-case）；编号区 `NNN_kebab-case.md` 流水不重排。
- 记忆 `YYYYMMDD-<slug>.md` 最后更新日期制，更新即改名并同步索引。
- 时间点推断不得冒充当前系统状态；历史轮次是当时事实快照，保留不改。

## 提交

- 标题中文祈使句（做了什么）；正文补为什么与关键取舍。
- 一个 commit 一个主题；附 `Change-By` / `Agent` / `Model` trailer；禁止伪造
  Reviewed-By、Co-authored-by 等未经本人确认的信息。

## 代码

- 注释中文；CLI-first 分层（命令/应用服务/领域/适配器）；`npm run check` 全绿才收工。
- 患者可见状态保持单一来源（正文、结构化响应、持久化、恢复共用）。

## 患者可见文本

- 通俗科普语言，老百姓可懂可执行；区分青少年/成人、轻症/重症话术（客户口径）。
- 不出现内部载荷（字段名、协议代号、`pregnancy=no` 之类）；方案带来源与视频引用。
- 医学条目只来自 truth：名单外穴位/疗法零出现；零命中明说「没有足够依据」。
