# Web 试用版非智能体报价闭环

> 2026-08-17。当前状态：实现候选已完成，未提交、未部署、未取得客户验收。

## 目标

冻结等待客户拍板的智能体科普路线，只核验报价中其余 Web 试用能力是否从管理端或患者输入
真实走到服务端持久化与患者回显；发现确定性缺陷就修复，并把关键路径固化为浏览器回归。

## 非目标

- 不改变千问、RAG、无命中降级、问卷、证型、分期或方案规则。
- 不建设原生微信小程序、微信登录、正式 PostgreSQL/COS 或正式生产环境。
- 不增加复杂统计、调理方案后台编辑、微信订阅消息等报价外能力。
- 不把自动化通过表述成客户验收、医学批准或生产就绪。

## 范围与依据

范围服从 `vault/truth/抗敏先锋AI小程序报价表.md`。本轮覆盖症状评估、科普内容、基础页面、
文章管理和视频管理；文章“推送”沿用作者已确认的应用内全员站内消息口径。知识库只复核既有
管理生命周期，不改变智能体检索和回答路线。

## 本轮缺陷与修复

管理 Web 打开文章或视频编辑表单时，曾把列表响应中的服务端隐藏字段一并放回表单状态；提交
时空 `methodTags` 被更新契约拒绝，页面显示“编辑”但实际返回 422。现在通过字段白名单只保留
页面明确可编辑的值，服务端修订号和隐藏元数据不再混入业务变更载荷。

## 依赖与风险

- Web 试用使用开发身份和临时 SQLite；正式身份、正式存储和原生小程序仍依赖客户资源。
- 浏览器自动化使用无身份测试内容，不代表真实科普素材已经完成客户审核。
- 客户 20 号返回后的智能体边界决定可能影响知识内容，但不改变本轮 CRUD 与患者内容闭环。
