# 原生微信小程序非智能体薄壳

> 日期：2026-08-17
> 状态：实现已提交为 `bb60564`，待 PR 合并；未上传、未部署，未经过真实 AppID、真机或客户验收

## 目标

复用现有患者命令协议，先完成报价中不依赖客户判断的原生小程序公共骨架和非智能体页面。
现有患者 Web 是唯一视觉基线：原生端只把同一信息层级、文案、配色和资产转换为微信组件，
不另行设计一套界面。后续微信账号就绪后只需联调身份与合法域名，不再从页面结构起步。

## 非目标

- 不实现或改造问助手、问卷、证型、分期、方案和医学规则；
- 不实现原生站内消息，不把 Web 已实现等同于小程序已实现；
- 不申请、保存或猜测客户 AppID、AppSecret、合法域名与隐私授权内容；
- 不上传体验版、不提交审核、不部署服务端。

## 本轮范围

- 四入口自定义底栏与中央“记录”动作；
- Web 同源品牌横幅、首页双服务模块、依据卡、今日任务、趋势和推荐内容；
- 首页概览、公开文章和视频入口及真实空态；
- TNSS 四项症状新增/修改、健康数据同意、月历和趋势展示；
- 文章/视频列表、详情及媒体地址转换；
- 公共请求免登录，私有请求经 `wx.login` 换取 Bearer，会话 401 只重试一次；
- 当前微信登录未配置时 fail-closed，不调用 `wx.login` 或身份接口。

## 依赖与风险

| 依赖或风险 | 当前处理 |
| --- | --- |
| 客户小程序账号与 AppID 未就绪 | 仓库 AppID 留空，仅保留本机选择入口 |
| 当前试用服务关闭微信登录 | 配置开关关闭，患者私有功能明确不可用 |
| IP 地址不是正式小程序业务域名 | 仅作开发者工具公共接口调试，正式联调需合法 HTTPS 域名 |
| 问助手路线等待客户反馈 | 页面仅标注待确认，不连接或扩写智能体能力 |
| 原生消息尚未实现 | 明确留作后续报价差距，不用 Web 能力冒充 |

## 验收方式与证据

- `node scripts/check-miniprogram.mjs`：校验页面四件套、自定义底栏、事件函数、AppID/密钥边界与 JS 语法；
- 同一检查还校验品牌横幅和助手静态图与 Web 正本逐字节一致，以及五格底栏选中索引；
- `node --test dist/tests/miniprogram-shell.test.js`：覆盖公共免登录、Bearer 登录、401 重登、登录关闭和 42 格日历；
- `npm run check`：纳入全量类型、架构、构建、Node 与浏览器门禁；
- 微信开发者工具已成功编译，问题面板为 0；首页、日历、我的和科普空态在 iPhone 模拟器完成目测。

开发者工具空 AppID 游客模式仍会产生微信内部接口告警，且本轮没有真实身份、合法域名、
真机、弱网、完整页面逐项目测或客户验收证据，因此不能据此宣称原生小程序可上线。
