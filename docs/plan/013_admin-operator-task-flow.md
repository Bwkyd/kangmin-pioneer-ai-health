# 管理后台按运营任务重组内容入口

> 日期：2026-08-26
> 状态：已实现、合并并部署；本文作为历史计划档案
> 最终基线：`main@bd2eb6b`

## 目标

让不具备开发背景的运营人员按实际任务完成内容维护，而不是先理解素材、索引和存储等内部
对象。管理后台围绕“新增文章、上传视频、添加 AI 知识”组织入口，并控制长列表的浏览成本。

目标任务流：

```text
文章管理 → 直接上传封面或正文图片
视频内容 → 直接上传视频和封面
AI 知识库 → 上传资料 → 建立索引 → 检索测试 → 启用
```

## 已确认设计

### AI 知识库

- 面向运营人员的“智能体知识库”统一改为“AI知识库”；只改可见运营术语，不机械修改
  truth、历史档案、命令、API、类型或数据库标识。
- 新增知识形成连续闭环：上传资料、补充名称/来源/目录、解析建索引、单资料检索测试、明确
  启用；未启用资料不得参与患者真实问答。
- “编辑”改为“修改信息”，资料正文变化使用“更新文件”；重新解析、建索引和测试后才能
  恢复启用，不能静默沿用旧状态。
- 当前目录和筛选结果每页显示 20 条；翻页保留目录、搜索词和状态，数据变化后回到最近有效页。

### 文件与素材

- 一级侧栏移除“素材库”。文章、视频和 AI 知识分别在自己的任务内上传文件，上传进度、
  失败原因和重试也留在当前任务中。
- 底层统一素材存储、对象存储适配、引用关系和安全校验继续保留；复用、替换或清理文件以二级
  “文件管理”提供，并显示文件用途、引用去向和业务状态。
- 已被文章、视频或知识引用的文件不能直接删除；隐藏入口不等于删除底层能力或现有数据。

### 视频、工作台与患者分类

- 管理后台视频内容每页显示 20 条；筛选变化后回到第一页，编辑、预览、发布或下架后保留仍
  有效的当前页，失效时回到最近有效页。
- 工作台按“今日待办 → 快捷新建 → 内容概览”组织，快捷入口直接进入文章、视频和 AI 知识
  的新建任务，不再展示需要技术解释的等权指标。
- 文章和视频使用服务端稳定分类标识。文章只有面向全部人群的“科普文章”，时间仅用于排序；
  视频按人群、方案类别和细分类组成树，并允许显式多选叶节点。
- Web、小程序和后台读取同一注册表；运行时不根据标题猜测分类，未决迁移内容失败关闭。

## 非目标与边界

- 不改变问卷、证型、分期、调理方案或其他医学规则。
- 不把知识检索测试解释为医学审核、客户验收或患者端效果证明。
- 不增加素材审批、复杂标签、多人审核、批量导入或数字资产管理系统。
- 小程序开发版上传不等于体验版、真机视觉验收、微信审核或正式发布。

## 验收方式

- 桌面端和 `390×844` 真实浏览器贯通文章、视频和 AI 知识任务。
- 使用超过一页的数据验证分页边界、筛选组合、跨页操作和失效页回退。
- 验证未启用知识不进入患者检索，已引用文件不能删除，升级前后引用和患者内容不变。
- 对分类覆盖缺失、非法、停用、非叶节点、类型不符、多关联、改名和未决迁移失败路径。
- 运行相关窄测、`cd src && npm run check`、PostgreSQL 16/S3 CI、`git diff --check`，并按
  `$km-review` 完成三视角复核。
