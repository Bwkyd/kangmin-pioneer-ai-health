## 患者视角

最终复核未发现 P0–P2。一般知识问题可由智能体请求搜索，当前方案解释可直接回答；零
命中和模型故障都说明缺少贴合依据并给出一个可继续回答的方向。急救提示不附带当前调理
方案来源，避免患者误认为可以继续调理；输出不暴露 JSON、字段编码或内部工具名称。

## 工程视角

最终复核未发现 P0–P2。`decideFollowUp` 只接受严格的 `answer`/`search` 二态 JSON；直答
路径零检索，搜索路径只有一次 `searchEnabled(query, 3)` 和一次最终生成，没有循环或第二
审阅模型。非法字段、空/过长检索词、模型不可用和检索异常均有测试。规则 verdict 在调用
前由服务端重建，只作为只读输入；症状补充测试确认不会修改既有证型和分期。DeepSeek
模型名可由环境注入，缺省值保持原行为。

## 医学安全视角

最终复核未发现 P0–P2。方案外穴位或疗法在模型调用前拒绝；直答与检索回答都继续经过
穴位、方法、参数和疗效边界校验。完成评估后的紧急表现由服务端确定性阻断，不依赖模型
路由成功，也不触发搜索。检索内容只用于回答依据，不能反向改变证型、分期或方案。
