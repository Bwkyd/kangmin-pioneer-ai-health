# 学一学人群分类与小程序同构元反思

> 日期：2026-08-26
> 基线：`origin/main@60d1197` 加 `codex/issues-283-284-classification` 当前实现。
> 对象：人群分类、四入口标题、视频目录容器、五项导航。

## 患者可懂性视角

页面稳定使用“学一学”，四类内容入口不因登录能力消失；知识问答不可用时显示中性说明，不把配置错误暴露给患者。视频按成人/儿童、方案和症状目录查找，并保留“仅用于查找，不代表诊断或证型”的边界。未发现 P0–P2。

## 工程事实视角

首个回归证明旧逻辑会因共享标题把儿童视频放入成人目录。现以全目录唯一的显式分类为最高优先级，分类缺失或未知才使用全目录唯一标题兜底；分类别名或标题歧义均拒绝展示。Web 直接消费已单测的共享纯函数，小程序使用等价 ES5 实现并有页面级回归。

全量门禁首次发现既有加密篡改测试以随机密文尾部替换为 `AA`，极低概率不改变值而假红；改为确定性翻转首字符后连续 100 次和完整门禁通过。微信开发者工具因占位 AppID 无法编译，这是环境限制，不是通过项。修复后未发现 P0–P2。

## 医学安全视角

目录只筛选已发布内容，没有修改证型、分期、方案匹配、操作参数或禁忌。冲突和歧义按 fail-closed 隐藏，不让标题猜测覆盖明确人群分类。未发现 P0–P2。

## 元反思与相似变式

sequential-thinking 五步检查了分类与标题冲突、跨人群共享标题、同人群多证型共享标题、重复别名、未知分类、详情标题恢复、知识问答能力降级、底栏遮挡和旧功能回归。当前 P3 仅为真实 AppID 缺失；双端静态目录漂移由 #284 继续收敛，不能把本轮补丁冒充服务端分类注册表。
