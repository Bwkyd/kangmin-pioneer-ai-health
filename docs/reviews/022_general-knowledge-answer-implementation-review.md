# 一般知识回答实现复核

> 日期：2026-08-23
> 基线：`main@c9b4e4b` 加当前未提交评测与本轮实现。
> 对象：知识问答千问调用、一般知识放行、急症前置分流、患者端说明及回归测试。

## 患者视角

零命中不再固定说“资料不够”；真实组合根可直接解释鼻塞原因，且不显示内部检索状态。Web 与小程序
入口如实说明“优先参考后台资料，无贴合资料也可回答一般问题”。急症回答短、第一句可执行。
元反思发现初版逐句删除可能改变上下文语义，已撤回；回答恢复整段原子校验。

## 工程视角

默认知识端口从未配置的 DeepSeek 改为当前已配置千问，实验模型与运行时一致；思考明确关闭，JSON
和 500 字上限保持。失败仍回退固定文案，不外发部分供应商响应。发现一项 P2：组合根注释仍写默认
DeepSeek，已改为千问。完整检查、真实模型服务冒烟和真实组合根命令均有证据。

## 医学安全视角

一般知识作用域只放行非个人、非处方的病理因果；个人因果、确定诊断、孕期禁忌、数字参数、药物
动作和侵入操作仍不放行。明确急症不检索、不调用模型。发现一项 P1 变式：初版把裸“胸闷”也作为
急症，会误拦“鼻炎会胸闷吗”这类概念题；已收窄到胸闷憋气或其他明确急症信号并补反向测试。
