# 管理后台视频预览元反思与交付前复核

> 日期：2026-08-26
> 基线：`main@bfca852` 加 `fix/admin-video-preview-sizing` 当前实现。
> 对象：后台文章/视频预览入口、视频与封面尺寸、发布校验保留和浏览器回归。

## 患者可懂性视角

列表按钮原名“校验”，实际动作是打开患者端效果预览，容易让运营人员误判为已经完成发布门禁；
现统一为“预览”，工作台发布链路和下一步提示同步更新。预览弹窗继续明确展示“发布前校验已通过”
或缺失项，不把预览冒充发布。未发现新的 P0–P2 问题。

## 工程事实视角

后台原先没有为复用的患者端视频类名提供尺寸约束，竖屏视频按容器宽度等比放大后占满弹窗。
现将视频限制为最大宽度 `560px`、最大高度 `min(50vh, 480px)`，使用 `object-fit: contain`
保留完整画面；封面同步限制在容器内。文章、视频仍共用原预览命令，发布仍走原服务端校验和状态更新。

元反思发现首版测试只断言 CSS 属性存在，不能证明实际尺寸。已补移动端 `390×844` 与桌面端
`1440×1000` 两种视口的计算高度、实际宽高和不裁切断言，并锁定旧“校验”按钮消失、发布前
校验结果仍可见。真实浏览器 E2E 已贯通文章预览、视频上传/编辑/预览/发布/下架。P0–P2 清零。

## 医学安全视角

本轮只修改管理后台展示尺寸、运营文案和测试，不涉及问卷、证型、分期、调理方案、知识检索或
患者回答。操作提示、注意事项、免责声明和发布前服务端门禁均保留。未发现医学安全问题。
