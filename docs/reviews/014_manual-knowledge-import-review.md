# 福建手册知识导入三视角交付复核

- 日期：2026-08-22
- 基线：Issue #246，分支 `codex/manual-knowledge-import`，相对 `main@427d560`
- 对象：手册准备脚本、Markdown 分块、SQLite/PostgreSQL 混合检索、独立知识问答与实验 013

## 患者视角

首轮发现 P2：降级摘录暴露“资料章节/知识主题”内部前缀，并可能截断在半句话中；“热敏灸
是什么”还曾因错误标题继承返回间接灸内容。现已改为标准标题层级、移除内部前缀、按完整句
抽取，并以真实问法复核来源。患者可看到来源和免责声明；专业自操作请求会明确说明不能只按
知识资料给个体做法，并提供“问原理/用途/风险或咨询医生”的下一步。未发现遗留 P0–P2。

## 工程视角

首轮发现两项 P2：同级编校标题被最近标题历史误组为父子关系；长文的三个相邻切块可垄断
Top-3。现由准备脚本确定性规范层级，通用分块器遵守 Markdown 层级；排序采用 SQLite/PG
共用的混合评分与“每来源优先两块、资料不足再回填”。另发现准备脚本递归清空输出目录的
破坏性风险，已改为只允许覆盖固定 17 文件与 manifest，存在其他文件即拒绝。完整门禁及真实
全生命周期实验通过，未发现遗留 P0–P2。

## 医学安全视角

首轮发现 P1：明确索要进针深度、儿童力度、孕期动作、塞鼻配制或灸法距离时，候选虽未泄露
参数，却可能回退为不明确拒绝的专业原文。现对“专业方法 + 明确做法/参数”和特殊人群个体
动作在模型前降级；概念例外只允许单一来源完整支持且不含数值单位、进针、剂量、力度、深度、
方向、疗程、取穴或已知穴位。手册仍是知识，不进入 truth 或个体方案裁决。5 条真实高风险题
和按揉变式通过，未发现遗留 P0–P2。

## 汇总

本轮共发现并修复 P1×1、P2×3；复核后 P0/P1/P2 为 0。测试通过不代表临床批准或客户验收；
生产仍需先备份并在候选数据库建立全部索引，完成检索与安全回读后才能统一启用。
