## 患者可懂性视角

文章只显示作者确认的“科普文章”，时间仅用于最近更新排序；视频分类按成人/儿童、方案类别与细分类显示完整路径。患者端不暴露迁移原因、数据库字段或内部状态。未发现 P0–P2。

## 工程事实视角

服务端注册表以稳定 ID、父子关系、人群、顺序、启停和可选叶节点为权威；写接口拒绝显示名称、未知 ID、异类型 ID、非叶节点和停用分类。SQLite 与 PostgreSQL 均在内容事务内同步多对多关联，发布再次校验，PostgreSQL 对分类行加共享锁。管理后台、Web 与小程序读取同一注册表并按 ID 筛选，旧标题猜测实现已删除。

首轮发现 1 项 P1：无法唯一迁移的旧已发布视频虽然没有分类关联，仍可能通过直达详情继续可见。已让两种数据库迁移把 unresolved 视频置为已下架、关闭患者可见并清空发布时间，同时保留原内容和迁移报告供人工选择。随后复核“文章只有一个分类”的作者决定，确认所有存量文章都存在唯一映射，不应因旧脏字符串被误下架；迁移现统一关联 `article-general`。回归覆盖文章唯一归类、未知视频下架、全部 truth 视频 ID/数量与分类矩阵。修复后未发现 P0–P2。

本机未配置 `KANGMIN_TEST_DATABASE_URL`，PostgreSQL 真实契约由 GitHub CI 的 PostgreSQL 16 服务强制执行，不能把本地跳过写成通过。

## 医学安全视角

视频映射逐项来自 `vault/truth/视频大全.md`，文章分类来自作者本轮确认；未知、重复或无法精确匹配的存量 fail-closed，不按标题相似度或正文推断成人/儿童归属。显式多选不会自动扩散到另一人群，也未改变证型、分期、调理方法、操作参数或禁忌。未发现 P0–P2。
