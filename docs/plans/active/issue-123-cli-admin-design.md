# Issue #123：患者 CLI 与管理员后台设计

## 目标

形成一份只读设计文档，冻结患者 CLI、管理员 CLI、登录角色、简化用户数据视图和薄前端边界。

## 范围

- 患者 `kangmin` 主入口和四类命令。
- 独立 `kangmin-admin` 管理入口。
- 单一 `admin` 角色，可分配给多个管理员账号。
- 管理员查看简化用户、会话和健康记录数据。
- 内容、知识、临床候选和发布门禁。

## 非范围

- 不实现 CLI、数据库、登录、Agent 或前端。
- 不批准临床候选或接入花粉数据源。
- 不修改 `legacy/`。
