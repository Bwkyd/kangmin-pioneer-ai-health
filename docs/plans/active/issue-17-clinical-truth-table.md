# Issue #17：生成关键规则确认单

## 目标

把开发分析发现的关键临床决策压缩成简短确认单，供客户导师或临床负责人书面确认；开发方收到回复后再把候选规则升级为正式规则和测试。

## 范围

- 确认证型数量、T1/T5 优先级和原始 ARIA 二级严重程度。
- 单独列出 4 个无命中组合，请客户决定结果或补问方式。
- 确认 unknown 不得自动当成“否”。
- 以简洁文字为主，保留既有 Markdown 记录。

## 非范围

- 不修改或发布正式临床规则。
- 不把外部论文结论表述为客户产品的临床验证。
- 不代替导师或临床负责人批准无命中分支、严重程度口径或调理方案。
- 不合并、部署或关闭 Issue。

## 验收标准

- [x] 只保留需要客户判断的关键问题。
- [x] 5 证型、T1/T5、ARIA 二级严重程度均有明确确认入口。
- [x] 4 个无命中组合有简短填写区。
- [x] unknown 处理和临床批准信息可书面填写。
- [x] 已按用户要求压缩为可直接发送的文字确认内容。
- [ ] 客户导师或临床负责人完成确认。
