# Issue #17：生成证型 32 组真值表供临床确认

## 目标

依据客户交付的 T1～T5 候选规则，生成覆盖 5 个核心布尔输入全部组合的 32 组候选真值表，明确冲突、无命中和 unknown 处理口径，供客户导师或临床负责人书面确认。

## 范围

- 展开口渴、倦怠乏力、四肢不温、畏风、形寒肢冷的 32 种是/否组合。
- 按“T5 优先于 T1”的客户聊天结论生成候选结果。
- 标出无命中的 4 组组合。
- 附整表确认、例外修改、unknown 口径和批准记录。

## 非范围

- 不修改或发布正式临床规则。
- 不把外部论文结论表述为客户产品的临床验证。
- 不代替客户确定无命中分支、三级严重程度阈值或调理方案。
- 不推送、合并、部署或关闭 Issue。

## 验收标准

- [x] 32 种是/否组合无重复、无遗漏。
- [x] 每行注明命中规则和候选结果。
- [x] T1/T5 重叠行按候选优先级显示 T5。
- [x] 4 个无命中组合有单独确认入口。
- [x] unknown 处理和临床批准信息可书面填写。
- [ ] 客户导师或临床负责人完成确认。

## 风险

- 等级：高
