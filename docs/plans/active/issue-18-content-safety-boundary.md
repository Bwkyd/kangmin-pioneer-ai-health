# Issue #18：冻结儿童、专业操作与视频治理边界

## 目标

把客户资料中的儿童方案、专业操作和视频要求转换为默认拒绝、可审核、可测试的产品安全边界。

## 范围

- 儿童年龄、监护和专项审核边界。
- A/B/C 专业操作展示边界。
- 视频编辑、临床审核和发布职责。
- 视频下架及历史引用行为。

## 非范围

- 不批准具体方案、穴位、时长、疗程或视频内容。
- 不实现方案、视频、身份、权限或存储功能。
- 不修改产品正式临床规则。
- 不合并、部署或关闭 Issue。

## 验收标准

- [x] 本轮只处理 Issue 明确列出的 4 个实体。
- [x] 每类操作均有普通用户端展示或禁止规则。
- [x] 儿童内容不得机械复用成人内容。
- [x] 视频发布、下架和历史引用行为可形成自动化测试。
- [ ] 客户导师或临床负责人书面确认医学边界。

## 风险

- 等级：高
- 数据库/权限/临床规则/核心接口/部署影响：本轮仅形成候选决定；未经书面确认不得实现或发布医学内容。
