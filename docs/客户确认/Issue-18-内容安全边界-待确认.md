# Issue #18：儿童、专业操作与视频治理边界（待确认）

> 本文件只冻结产品安全边界，不批准任何具体调理方案、穴位、时长、疗程或操作视频。

## 一句话结论

默认不向普通用户展示高风险操作教程；儿童只使用单独审核的低风险内容；视频必须经过临床审核和发布，已下架视频不得继续播放。

## 1. 儿童展示边界

- 不满 14 周岁的用户必须由监护人代填并完成监护人同意。
- 儿童内容必须设置明确适用年龄，不能把成人内容简单缩短时长后复用。
- 儿童端只允许展示经儿童专项临床审核的 A 级低风险内容。
- 未完成年龄确认、监护人同意或儿童专项审核时，不返回方案和操作视频。

说明：《个人信息保护法》将不满 14 周岁未成年人的个人信息列为敏感个人信息，处理时应取得父母或其他监护人的同意。年龄边界用于隐私和监护流程；具体医学内容仍需临床负责人批准。

## 2. A/B/C 专业操作边界

| 等级 | 普通用户端规则 | 典型候选 |
| --- | --- | --- |
| A | 临床审核通过后，可展示完整低风险健康教育、注意事项和停止条件 | 轻柔按揉、非侵入性健康教育 |
| B | 只展示风险说明和“需专业人员评估/指导”，不展示可照做的完整步骤 | 艾灸、刮痧、拔罐、耳穴压豆等候选 |
| C | 不展示操作步骤、穴位组合、器械、剂量、时长或疗程，只提示前往专业机构 | 针刺、皮内针、刺络放血、含药物敷贴 |

- 客户资料中的详细操作文本不能直接进入普通用户端或模型提示词。
- 未明确分级的内容一律按 C 级处理，直到临床负责人书面降级。
- 大模型不得改变风险级别、补充步骤或绕过禁忌。

## 3. 视频审核与发布

- 内容编辑者负责上传和填写来源、年龄、风险等级、禁忌及停止条件。
- 临床审核者负责医学内容审核；技术管理员不能代替临床审核。
- 发布者只能发布已通过临床审核的不可变版本。
- B/C 级内容及儿童内容不得由同一账号同时完成编辑、审核和发布。
- 缺少审核人、审核时间、适用年龄、风险等级或禁忌时禁止发布。

## 4. 下架与历史引用

- 视频下架后，新评估不再返回该视频。
- 历史结果保留当时的视频 ID、版本、标题和审核记录，但不保留可播放地址。
- 历史页面显示“该视频已下架”，同时保留经审核的方案文字和安全提示。
- 下架不删除审计记录；恢复展示必须生成新发布记录，不直接篡改旧版本。

## 来源边界

- 客户需求资料：说明需要儿童方案、文字、穴位图片、工具图片和操作视频，但不等于批准普通用户自行执行所有操作。
- 客户整理的方案映射：包含针刺、放血、艾灸、药物敷贴等高风险细节，仅作为待审核输入。
- 法律边界：[《中华人民共和国个人信息保护法》第二十八条、第三十一条](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)。
- 最终医学展示权限：以客户导师或临床负责人书面批准为准。
