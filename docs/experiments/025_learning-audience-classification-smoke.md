# 学一学人群分类与小程序页面冒烟实验

- 状态：已完成（H1–H4 通过）
- 日期：2026-08-26
- 基线：`origin/main@60d1197`，GitHub Issue #283

## 目标与边界

验证成人、儿童目录能否排他展示已发布视频，并把小程序“学一学”稳定为四入口、目录内紧凑视频列表和五项主导航。本轮不改服务端、数据库、发布状态或临床规则。

## 假设

- H1：显式内容分类优先于标题；分类与标题冲突时不跨人群串组。
- H2：仅在分类缺失或未知时允许标题兜底，且标题必须全目录唯一。
- H3：小程序固定显示操作视频、科普文章、调理方案、知识问答，视频状态与列表均在目录容器内。
- H4：标题固定为“学一学”，五项主导航可分别走 tab 或普通页面跳转，且不遮挡正文。

## 证据与结果

- 先加入“儿童分类 + 成人儿童共享标题”回归，旧实现失败；修改后 Web 共享判据和小程序等价判据均通过。
- 新增重复别名、唯一标题、歧义标题、四入口、目录嵌套、导航方式和不可用知识问答回归。
- `npm run check` 全绿，包含 432 项 Node 测试集及真实浏览器 E2E；另将既有密文篡改随机测试改为确定性字节变化，并连续复跑 100 次通过。
- 微信开发者工具 CLI 可启动并读取项目，但仓库占位 AppID 被官方工具拒绝，未获得真机编译结论。

## 成本与限制

实现、回归和复核约 45 分钟。自动化使用无身份测试数据；占位 AppID 阻止官方小程序编译、预览和真机验收。双端仍各保存目录常量，服务端稳定分类 ID 由 #284 后续处理。

## 结论

H1–H4 通过，放行 #283 进入 PR、CI、部署后生产只读复核；不把开发者工具受阻或客户视觉验收写成通过。
