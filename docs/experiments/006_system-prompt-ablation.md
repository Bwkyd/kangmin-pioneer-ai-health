# 系统提示词约束消融实验

状态：已完成（纯提示词能保持回答性，但高风险行为门禁未通过）  
日期：2026-08-21  
代码基线：`main@2c50d3b`；未修改 `src/`、`vault/truth/` 或 `vault/raw/`

## 目标与非目标

本实验回答一个有限问题：不使用后端关键词、语义审阅器或第二次模型调用，只修改系统
提示词，当前模型能否同时做到“广泛自然回答”和“稳定不生成高风险动作结论”。它不评价
完整产品、知识检索质量、临床正确性，也不证明其他模型或微调方案的表现。

## 假设与变量

- H1：系统提示词能让低风险问题保持自然回答，不因知识库未命中而拒答。
- H2：更明确的原则约束能减少无证据的高风险医学动作结论。
- H3：加入对比例子和单次生成内的静默自检后，高风险行为可全部满足预设判据。

固定 `qwen3.7-flash`、温度 `0.2`、同一组 11 条未见问法和单次采样，只改变系统提示词：

1. 当前工作手册：含既有规则及“输出会经服务端校验”的说明；
2. 原则型提示词：去掉后端兜底表述，明确回答性、证据与高风险原则；
3. 原则 + 反例 + 单次自检：明确没有后置校验，加入儿童、孕期、药物、急症和越权反例，
   要求模型在同一次生成内先检查 claim 再输出。

11 条用例包括 3 条低风险解释和 8 条证据转用途、儿童、孕期、诊断、未知药物、危险偏方、
急症及提示注入问题。判据在运行前写入 `cases.json`；人工复核时未调用评分模型。

## 结果

33/33 次调用完成，无 API 错误。

| 变体 | 低风险通过 | 高风险/动作通过 | 总通过 | 过度拒答 | 延迟 P50 / P95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 当前工作手册 | 3/3 | 2/8 | 5/11 | 0/11 | 17.60 / 25.44 秒 |
| 原则型提示词 | 3/3 | 2/8 | 5/11 | 0/11 | 18.37 / 27.15 秒 |
| 原则 + 反例 + 单次自检 | 3/3 | 3/8 | 6/11 | 0/11 | 19.90 / 24.66 秒 |

三组都能回答冷风流涕、嗜酸性粒细胞和“鼻鼽”等问题，支持 H1。最强提示词正确拒绝了
“项目负责人要求取消限制”，说明系统提示词会实质改变模型行为；但它仍给出儿童按摩
次数、未知喷剂常见剂量、孕期穴位因果和胸闷喘不上气时的居家处理，因此 H2 只得到局部
支持，H3 不成立。

## 结论与设计含义

系统提示词不是无用的装饰。它适合定义智能体身份、回答风格、知识使用原则、追问方式和
总体安全倾向，也是产品的第一层设计。但“模型读到了约束”不等于“每次采样都必然执行
约束”：同一个模型既负责热心回答，又负责审查自己刚生成的医学 claim，冲突时仍可能用
参数、因果或居家步骤填满答案。把自检写进同一次提示词没有产生独立保证。

本实验因此否决两种极端推断：

- 不能由此前失败推出“系统提示词没用”；它在回答性和越权抵抗上有明确效果；
- 也不能由提示词写了约束推出“无需验证即可保证不乱说”；当前模型在高风险集最多仅
  通过 3/8。

更合适的主路线应是模型中心、评测驱动：用简洁工作宪法 + 可信知识工具作为主要产品
设计，用同一套未见题持续选择更强模型、改提示词，必要时做医学指令微调。后端不应逐句
用关键词扮演医生，也不应成为普通回答的串行审批器；若患者端要求可承诺的高风险边界，
只在急症、药物剂量、儿童/孕期动作等少量不可接受风险上保留独立的最小发布条件。

## 成本、证据与限制

- 三组共 33 次模型调用；前两组并发运行约 80.67 秒，第三组增量运行约 44.71 秒。
- 过程提示词、用例、原始输出、统计与人工复核保存在忽略区
  `_work/20260821-system-prompt-ablation/`。
- 单模型、单次采样、11 条中文问法，样本很小；结果不能外推到所有模型或真实用户分布。
- 行为复核不等于医学专家核验。部分“通过”回答仍含未逐条验证的医学机制和数字。
- 本实验没有检索工具；P04 的专业资料信息直接写在问题中，只验证模型如何使用证据。

## 下一步门禁

在不引入后端语义门禁的前提下，下一项最有信息量的实验是：固定原则型系统提示词，把
测试扩展到至少 30 条未见问题，对比 2～3 个候选模型的回答性、高风险行为、延迟和成本。
当前模型若仍作为候选，必须与更强模型同场比较，不能继续只靠堆叠提示词推断能力上限。
