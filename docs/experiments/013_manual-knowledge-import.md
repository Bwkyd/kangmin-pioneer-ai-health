# 福建中医药适宜技术手册知识导入实验

- 日期：2026-08-22
- 状态：已完成，放行 Issue #246 的受控实现与分批导入
- 代码基线：`main@427d560`；生产基线为 4 份 enabled 知识、4 个切块与向量
- 范围：只把手册作为同一检索集中的参考知识，不修改 truth、证型、分期、方案或操作参数裁决

## 假设与变量

原始目录含 18 份 Markdown 和 12 张刮痧示意图，其中一份第一章汇编稿与五份分稿重复，
其余多数文件带整本目录。实验比较原始段落分块、去目录后纯向量分块，以及“规范标题层级
+ 章节上下文 + 0.15 字面重合权重 + Top-K 来源多样化”。固定使用 DashScope
`text-embedding-v4`，以 17 条跨章节患者问法测 Hit@3，并另以 5 条专业自操作问法测发布边界。

## 证据与结果

- 原始分块共 73 块，其中 14 块含重复整书目录；虽为 17/17 Hit@3，但命中受到目录污染，
  不能作为可用基线。
- 第一轮净化去除全部目录污染、保留 12/12 图注，但因编校稿把父子标题写成同级，纯向量
  仅 13/17；修正章节身份后为 15/17。
- 真实“添加→132 块分块→建立向量→启用→检索”首次为 16/17；诊断发现同一长文占满
  Top-3。采用每份资料优先最多两个切块、语料不足时回填后达到 17/17。
- 17 份规范正文和一份 manifest 可重复生成；第一章汇编重复稿明确排除。12 张图只转为原图
  路径与图注，未声称文本模型理解图中手法。最终 manifest SHA-256 为
  `3a52e6ec0b754230d4d900c81dbe929496a027a0db4e32d18707eafd54bf7248`。
- 5/5 专业自操作题（进针深度、儿童力度/次数、孕期动作、塞鼻配制、灸法距离/时长）均在
  模型前确定性降级；“热敏灸是什么”等概念问法仍可返回来源内定义，不恢复宽泛疗法词拒答。

## 采用结论、成本与限制

采用 17 个可追溯知识项，而不是直接上传 18 份 raw 文件。净化只删除编校元数据、重复目录
和重复汇编，正文、参考文献、风险与禁忌保留；图片保留图注和原件路径。混合排序只影响
enabled 知识的相关性，不承担可信度、用途或医学授权。

实验调用真实向量服务并在隔离 SQLite 中完成全生命周期，耗时为秒级；未写生产数据。问法集
规模有限，17/17 不是临床验收或开放域准确率。生产必须先创建并索引全部新知识，复核数量、
哈希、检索和高风险降级后再统一启用；任一步失败时不得部分启用。
