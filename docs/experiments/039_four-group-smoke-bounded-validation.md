## 假设与边界

把报价内行为分成核心·智能调理、辅助·内容供给、次要·症状管理、次要·基础壳四组，验证已有高信号测试能否作为小步改动前的快速确认入口。本实验只运行既有测试并注入零命中反证，不修改生产代码、数据库、truth、患者数据或外部环境。

统一判据：每组先构建再运行窄测；正向路径和既有拒绝、停用、失败、重试、缺失值断言必须真实命中；零命中仍退出 0 时记录为入口缺口，不能冒充稳定冒烟。
