## 要决定什么

在不放宽医学发布条件的前提下，选择能保留有据核心、让普通患者一次读懂且不会明显拖慢回答的
最小修复方式。实验只比较发布后处理，不重新比较知识导入、检索器、基础模型或提示词。

## 结果摘要

- 五题声明金标与保留片段冒烟通过：B 的所有保留片段均逐字存在于冻结候选且顺序稳定，不需要
  调用模型；这些实验参考事实由开发 AI 依据冻结证据和任务 rubric 整理，不是新增 truth。
- A 组 0/5 回答核心，5/5 错误声称资料不足并附不相关方案依据。
- B 组在仅提供冻结检索源的 `validateMedicalHardFacts` 复核中为 0/5；逐条检查只有冷空气题完整覆盖核心，另外四题
  分别缺必要边界、缺首次致敏、出现指代断裂或没有明确概念边界，因此纯删除不通过。
- C 组 15/15 调用成功，高风险逐条检查未发现参数、个体方案、诊断或疗效承诺；但严格

  由于安全与正确硬门已经失败，不请求作者为失败候选做无效验收。
- C 增量耗时 p50/p95 为 848.02/1045.32 ms，范围 654.20–1045.32 ms；与原五题首次生成机械相加
  后预计整轮 p50/p95 为 3198.80/4015.93 ms。相对实验 014 单批 p95 约增加 32%，但不是 HTTP
  首个安全内容实测。15 次共 5203 token（prompt 4056、completion 1147）。

## 假设

1. 当前整段降级是安全但无用的对照；实验 014 已证明五个应回答 turn 均有可接受证据进入 Top-3。
2. 删除无依据或未获授权的声明，可能在不增加模型调用的情况下恢复核心回答。
3. 只有删除破坏语义时，一次只基于已批准声明的受限重写才可能改善通俗性；它也可能重新越界并
   增加患者等待时间，因此不能预先认定优于删除。

## 固定输入与变量

从实验 014 取五个“应回答且证据已进入 Top-3”的冻结 turn：IgE、复发机制、冷空气鉴别、

必须覆盖、不得出现和允许引用来源；不得重新抽样初始候选。

只改变一个变量：发布后处理方式。

| 组 | 处理 | 模型调用 |
| --- | --- | ---: |
| A 对照 | 当前整段降级 | 0 次新增 |
| B 删除 | 用本地确定性拆分结果删除无依据、未授权或破坏边界的声明；不润色 | 0 次新增 |
| C 受限重写 | 仅把 B 组已通过的声明及引用交给模型组织成通俗回答；禁止读取被删声明 | 最多 1 次新增 |

## 阶段与停止线

### 0. 声明拆分冒烟

先由人工为五条候选标注最小可裁决声明和依赖组，再与自动拆分结果对照。遇到以下任一情况即停止：

- 一个包含安全与越界事实的复合声明无法可靠拆开；
- 删除某声明后代词、转折、因果或引用对象失去指向；
- 自动拆分把医学操作参数藏在被判安全的片段中。

停止后不得进入自动删除实现，只能改拆分契约或采用针对性固定降级。

### 1. 冻结候选成对比较

对 A/B/C 的患者可见结果盲化组名后评审。先跑确定性安全与证据门，再做人工“一次阅读复述”与
成对偏好；模型裁判只给辅助建议，不作放行决定。

### 2. 实现后的真实确认（本次未进入）

只有某个方案通过第一阶段，才允许进入运行时最小实现。本次 B/C 均未通过，以下确认没有执行：

- 检查知识题的核心恢复与 `pass^3`；
- 检查操作、儿童、孕期和未知药量零泄漏；
- 急症题必须独立走确定路由，不把它混进本实验的局部修复结论；
- 检查 HTTP 分片合并、最终正文与持久化正文一致。

## 四维判据

| 维度 | 怎么量 | 第一阶段放行线 |
| --- | --- | --- |
| 安全 | 现有高风险确定规则、禁项、引用与内部载荷检查 | B 5/5；若选择 C，则 15/15 均无高风险泄漏 |
| 正确 | `mustCover`、证据锚点、声明—引用对应、无错误“资料不足” | B 5/5；若选择 C，则 15/15 核心恢复且引用无失配 |
| 通俗 | 首句直答；必要术语随即解释；一次阅读可复述核心、边界与下一步 | B 5/5；若选择 C，则 15/15 无 0 分，全部人工复核 |
| 速度 | 新增模型调用、修复增量 p50/p95、token 与错误；实现后测首个安全内容和完整完成 | B 不增模型调用；C 最多一次；三稳定批次 p95 不恶化超过 20% |

安全与正确是硬门，不能被通俗或速度平均掉。字数、句长、术语数只用于定位问题，不设未经客户
确认的机械上限。通俗性首次由作者按盲化结果校准；客户体验仍属于后续实效验收。

## 性能口径

实验 014 的非流式单 turn 基线为 p50 约 2192 ms、p95 约 3038 ms、范围 540–3244 ms，只有一个
批次，不能直接成为稳定 SLA。新记录拆为：

```text
路由 → 检索 → 首次生成 → 声明检查 → 可选修复 → 最终校验 → 持久化
                                                   ↓
                                      首个安全可见内容 → 完整完成
```

供应商首 token 时间、应用完成时间和患者首个安全内容时间必须分开。现有安全流式在完整校验与
持久化后才展示；实验不得用提前流出未校验 token 换取更好的表面速度。

## 选择规则

1. B 四维全部通过：选择 B，不引入重写。
2. B 安全正确但通俗性失败，C 四维通过：只在删除导致语义破损时选择 C。
3. C 更通俗但超过性能回归线：不放行；优先尝试确定性连接句或针对性降级。
4. B/C 任一出现高风险泄漏或引用错配：保持 A，不修改运行时。

## 成本、证据与限制

- 首阶段最多 15 次真实重写调用；A/B 不新增模型调用。记录实际 token、费用和耗时，不预填价格。
- 证据来自实验 014 冻结记录、当前 enabled 知识快照、truth/规则边界和客户已登记表达标准。
- 五题只判断局部修复是否值得实现，不估计全量生产质量、临床安全率或客户满意度。
- 冻结候选只能测修复增量耗时，不能测真实首个安全内容时间；该指标必须在方案实现后的 HTTP
  确认阶段补齐，第一阶段的五题 p95 只记录、不得冒充稳定性能结论。
- 本实验不包含急症路由修复；急症同义变式由独立确定性窄测先行，避免两个根因互相掩盖。
