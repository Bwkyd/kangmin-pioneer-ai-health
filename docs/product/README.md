# 客户决策

本目录只保存需要客户拍板的选择题。普通产品设计和客户试用计划放入 `docs/plan/`；
待决策事项以本目录中的决策单为准；若影响当前接续，board 只记录决策单链接和状态，
不复制完整选项。

## 使用流程

1. 复制 [`TEMPLATE_client-decision.md`](TEMPLATE_client-decision.md)，命名为
   `YYYY-MM-DD-<topic>-decision.md`；
2. 写明 2–3 个互斥选项、推荐项及对范围、成本、工期和体验的影响；
3. 客户回复后保留可核验出处并写入最终结论；后续 board 轮次记录回复、实施和验证
   状态。
