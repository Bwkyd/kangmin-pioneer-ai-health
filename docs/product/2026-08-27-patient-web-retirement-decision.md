# 患者 Web 退役与管理后台唯一入口决策

- 日期：2026-08-27
- 状态：作者已确认并实施
- 决策人：作者

## 决策

患者端只保留微信小程序；`src/web` 中的旧患者 Web 不再维护。浏览器侧只保留管理后台，服务根路径 `/` 与既有 `/admin` 都指向同一份后台构建，不再维护两份 HTML。

## 边界

- 不删除患者命令、健康记录、评估、内容浏览等服务端能力；它们仍服务微信小程序。
- 不改变 truth、医学规则、权限模型、数据库结构或患者数据。
- 管理后台继续通过同源 HttpOnly Cookie 和管理命令接口工作。
- 保留既有 `/admin` 链接，避免破坏书签、监控和运维入口；它只是同一后台的兼容网址，不是第二个应用。

## 验收

管理后台独立小壳可单独构建、类型检查和测试；真实浏览器在 390×844 与 1440×900 下完成登录、文章保存发布和模块导航；`/` 与 `/admin` 必须返回同一个后台根节点；小程序相关测试保持通过。
