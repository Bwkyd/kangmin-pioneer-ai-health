# 决策点 · 模型更换与开源借鉴

## 不可妥协项

| # | 不可妥协的 | 怎么算满足 |
| --- | --- | --- |
| 1 | 模型更换必须改善本项目真实失败 | 同一患者知识卡、同一 20 题下，P01–P05 保持 5/5，U/S 明确失败降到不超过 2/10 |
| 2 | 开源项目必须补当前缺口且不扩大报价 | 只借语义 RAG、评测或诊断方法；不是重新搭通用 Agent、训练平台或线上观测平台 |
| 3 | 结论必须可复现且不冒充医学正确 | 提示词、输入、输出和判据留档；自动裁判经人工校准；医学结论仍由作者/医学人员定标 |
| 4 | 许可证、隐私和维护成本可接受 | 明确许可证；患者资料不外发；学生团队能在现有 Node 项目与有限 GPU 资源下运行 |

## 要作的决定

是否停止换模型和训练路线，回到报价内实现语义 RAG 纵向切片。

## 排除项

- 不按综合榜单和 GitHub 星数选择医疗模型；
- 不把考试正确率等同患者对话质量；
- 不训练、不微调、不建设训练数据集；
- 不引入 LangChain/OpenCHA 一类完整运行时替换当前作品。
