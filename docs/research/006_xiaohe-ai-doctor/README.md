## 研究对象的口径

“小荷 AI 医生”不是一个单一入口：公开使用须知同时描述 App、小程序、网站/H5、抖音账号私信等入口，并说明不同入口能力可能不同。抖音上的“小荷 AI 医生”账号、App Store 中的 App、关联的 AI 健康咨询服务和“医生 AI 分身”均需分开看，不能把相关产品的能力混成一套。

本轮以官方产品页、App Store 页面、官方使用须知、隐私政策、用户协议和官方抖音账号为主；第三方截图只作为视觉走查线索，不作为事实依据。没有登录抖音或安装 App 做真机交互，因此按钮层级、实际响应、模型质量和当前版本行为仍待作者实测。

## 本轮结论

最值得欣赏的不是“AI 医生”这个称呼，也不是把抗敏先锋扩成通用医疗平台，而是这条产品闭环：

> 低门槛进入 → 先收集关键健康信息 → 多轮、可理解的健康咨询 → 报告/图片等资料解释 → 保留上下文与摘要 → 必要时转人工医生或线下服务。

这是根据官方公开入口、功能说明、历史/摘要与人工服务衔接说明抽象出的产品级推断，不代表小荷内部真实架构。

对抗敏先锋，首选只借**交互外壳和持续管理能力**：让患者更容易进入“鼻健康助手”，用快捷问题和受控追问完成信息收集，在规则判定后给出有依据的解释，并让患者能够回看摘要、继续追问和安全升级。现有项目仍只做过敏性鼻炎，不引入报告解读、用药识别、通用疾病问诊、医生交易或“AI 自主诊断”。
