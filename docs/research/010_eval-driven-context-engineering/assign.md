# 派活模板 · 评测驱动的患者 Agent 上下文工程

> 2026-08-21。后续阅读模型、RAG 或评测材料时统一使用，不按宣传功能平均用力。

```text
【材料】绝对路径或官方来源
【角色】要比的 / 要学的 / 零件

【逐条核查】
1. 它怎样选择每轮进入模型的最小高信号上下文？
2. 它是否区分来源角色、适用对象、已知事实与未知项？
3. 它如何评测有用性、依据性、高风险行为、延迟和多次一致性？
4. 它改进的是模型能力、运行时上下文，还是只做事后监控？

【预判——请证伪】
我怀疑它能改善平均表现，但不能单独保证患者回答零幻觉。请用原文、源码或实验结果证伪。

【证据格式】
逐条给“原生 / 部分 / 没有 + 文件:行号 + 一句话”，800 字以内。

【必须判断】
直接用 / 改造 / 只借鉴 / 不适合；给一个首选、一个备选和三个风险。
找不到就明确写没有。
```
