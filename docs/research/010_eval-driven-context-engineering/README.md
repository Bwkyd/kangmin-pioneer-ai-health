## 一句话结论

模型确实会产生无依据补全；评测不会在运行时拦住它，上下文工程也不能保证零幻觉，但两者
组合能把问题从“写一条规则修一个错误”改成“用未见题选择更好的模型、知识上下文和提示词，
并持续防回归”。首项应做上下文消融实验，而不是继续增加后端医学判断器。
